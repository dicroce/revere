the file linked from its name.

## Windows only: libraries compiled into BtbN's FFmpeg build

BtbN's lgpl-shared build of FFmpeg 8.1 statically links the libraries below into its DLLs (configure line embedded in avcodec-62.dll). Revere ships avcodec, avformat, avutil, swscale and swresample, so some of these (the ones only avfilter or avdevice use) are present only in part or not at all; all are listed to be safe. Their notices are Debian's copyright files for the same upstream projects, or the upstream licence where Debian doesn't package them.

## OpenCV's bundled libraries (Windows)

The Windows OpenCV build compiles in libjpeg-turbo, libpng, libtiff, OpenJPEG, OpenEXR, libwebp,
zlib, protobuf, Intel ITT, Intel IPP (ippicv/ippiw) and a few smaller pieces. Their licences, as
OpenCV installs them, are in [opencv-windows/](opencv-windows/).
